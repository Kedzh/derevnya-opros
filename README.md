# Опрос «Благоустройство нашей деревни»

Готовый опросник для социального проекта. Один файл — работает без интернета и без установки.

## Что в папке

| Файл | Для чего |
|---|---|
| `index.html` | Сам опрос. Открывается двойным кликом в любом браузере |
| `Code.gs` | Скрипт для Google Таблицы (принимает ответы) |
| `README.md` | Эта инструкция |

## Быстрый старт

1. Откройте `index.html` в браузере (Chrome, Edge, Firefox).
2. Проверьте, что вопросы листаются и выбираются.
3. Раздайте жителям: отправьте файл, скиньте на флешку, выложите на почту или откройте со школьного сайта.

Работает на телефоне — анкета адаптирована под экран.

## Подключение Google Таблицы (нужно один раз)

Пока это не сделано, ответы сохраняются только в браузере того, кто заполнил анкету. Чтобы ответы приходили к вам — 5 минут:

### Шаг 1. Создайте таблицу

На [sheets.google.com](https://sheets.google.com) → **Пустой документ**.
Назовите, например: `Отзывы жителей — проект`

### Шаг 2. Откройте редактор скриптов

**Расширения → Сценарии (Apps Script)**. Откроется редактор.

### Шаг 3. Вставьте скрипт

Удалите то, что там есть (`function myFunction() {}`), и вставьте всё содержимое файла `Code.gs`. Нажмите **Сохранить**.

### Шаг 4. Опубликуйте

1. Нажмите **Развернуть → Новое развёртывание**.
2. Тип → **Веб-приложение**.
3. **Описание**: `Приём ответов опроса`.
4. **Выполнять от имени**: `Меня`.
5. **Кто имеет доступ**: `Любой` ← *важно, иначе жители не смогут отправлять*.
6. **Развернуть**. Если спросит авторизацию — согласитесь (Google требует подтвердить, что скрипт безопасный; это стандартная процедура для своего аккаунта).

### Шаг 5. Скопируйте ссылку

После публикации появится **URL веб-приложения** вида:
```
https://script.google.com/macros/s/AKfycbXXXXXXXX/exec
```

### Шаг 6. Вставьте ссылку в опрос

Откройте `index.html` в блокноте (или в VS Code), найдите строку в начале скрипта:

```js
const GOOGLE_SHEET_URL = "";
```

и вставьте ссылку между кавычки:

```js
const GOOGLE_SHEET_URL = "https://script.google.com/macros/s/AKfycbXXXXXXXX/exec";
```

Сохраните. Готово — ответы идут в таблицу.

> ⚠️ Не публикуйте ссылку `script.googleusercontent.com` — это страница предпросмотра, работать не будет. Нужна именно ссылка, полученная после «Развернуть».

## Как проверить, что работает

Заполните анкету самому, затем откройте таблицу — внизу должна появиться новая строка. Если строка есть, но текст «поехал» — в таблице выделите все столбцы → вкладка **Формат → Число → Текст**, потом скопируйте туда анкету заново.

## Вопросы анкеты

1. Немного о вас (имя, возраст, проживание) — необязательные
2. **Чего в деревне больше всего не хватает?** — сквер / детская площадка / мост / спортплощадка / другое
3. **Что нравится в сквере или мосту и что хочется изменить** — два открытых поля
4. **Что важно в сквере?** — урны, освещение, навигация, велодорожки и ещё 9 вариантов + оценка важности от 1 до 5
5. **Считаете ли мост безопасным?** — и если нет, что именно тревожит (9 вариантов)
6. **Хотели бы вы помочь проекту?** — и чем именно можете помочь, контакт
7. **Что ещё хочется сказать?** — свободное поле
8. Согласие на обработку данных

Опрос условный: вопрос про безопасность моста раскрывается только если человек ответил «скорее нет» / «нет» / «моста нет» — не грузит людей лишним.

## Что делать с ответами

- **Обезличивание.** Перед публикацией итогов уберите из столбцов «Имя» и «Контакт» — в отчёте проекта они не нужны.
- **Сводка.** Столбец «Чего не хватает (главное)» — главный: он сразу показывает приоритет. Отсортируйте по нему и посчитайте, сколько раз упоминается мост.
- **Выгрузка для презентации.** Файл → Скачать → CSV, затем вставьте в таблицу-диаграмму.

## Если что-то не работает

| Проблема | Причина |
|---|---|
| Строки не появляются в таблице | Не вставлена ссылка, либо при развёртывании выбран доступ `Только я` |
| Ошибка 403 / 400 | Переопубликуйте скрипт: **Развернуть → Управление развёртываниями → ✏️ → Доступ: Любой** |
| Ответы не сохраняются вообще | Проверьте, что файл открыт из того же места, где лежит скрипт, а не из вложения в письме |
| Открывается «Скачать файл» вместо страницы | Скопируйте файл на рабочий стол и откройте оттуда |


Через минуту изменения появятся на сайте.

### ⚠️ Ссылка на таблицу лежит в коде открыто

В `index.html` строка `GOOGLE_SHEET_URL` содержит адрес веб-приложения Google Apps Script. В публичном репозитории эта ссылка видна всем — для открытой анкеты это необходимо, но следствия такие:

- в таблицу сможет отправить данные кто угодно, кто посмотрит исходник страницы;
- если таблица вам дорога — добавьте в `Code.gs` проверку источника или ограничьте приём.

Как защитить таблицу, описано ниже.

### Как закрыть таблицу от посторонних записей

В `Code.gs` добавьте в начало `doPost` проверку источника запроса:

```javascript
var allowed = 'kedzh.github.io';   // ваш домен
if (!String(e.parameter.host || '').includes(allowed)) {
  return ContentService.createTextOutput('{}').setMimeType(ContentService.MimeType.JSON);
}
```

Но учтите: браузер отправляет форму в режиме `no-cors`, поэтому `e.parameter.host` может быть пустым. Надёжнее проверять по секрету — в `index.html` подставьте в тело ещё одно поле `token`, а в `doPost` сверяйте его с константой.
